# Little Lemon Food Ordering App

This is the SwiftUI source code for the Little Lemon capstone project. 

**Note to the reviewer:**
Since this repository contains only the source files, to run the app in Xcode, please create a new iOS App project in Xcode, and drag all the `.swift` files from this repository into your project. 

The wireframe design is included in the repository as `wireframe.jpg`.

### Features implemented:
- 3-page Onboarding with validation.
- Persistent login using @AppStorage.
- Home screen with Hero section, Search bar, and Category filtering.
- Profile screen with user data and Logout functionality.
